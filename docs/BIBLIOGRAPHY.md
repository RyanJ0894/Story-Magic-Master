## Research Methodology Notes

### Evaluation Criteria Development

The 12-dimension rubric was developed by:

1. **Internal Analysis**: Reviewing AUTOSCORE_PLAN.md's 8-dimension framework
2. **Industry Survey**: Analyzing 10+ script coverage services' criteria
3. **Academic Review**: Incorporating Save the Cat structure elements
4. **Market Research**: Aligning with current greenlight criteria
5. **Practitioner Input**: Dialogue/character voice expertise from working professionals

### Weighting Rationale

| Category | Weight | Rationale |
|----------|--------|-----------|
| Concept | 25% | High-concept sells; logline is first impression |
| Structure | 25% | Industry expects beat-perfect pacing |
| Character | 25% | Castability drives greenlight decisions |
| Craft | 25% | Dialogue/visual execution separates amateurs |

### Confidence Levels

| Source Type | Confidence |
|-------------|------------|
| Academic/Book | High - Peer-reviewed or industry-validated |
| Industry Service | High - Real-world application |
| Blog/Article | Medium - Professional opinion |
| Wikipedia | Medium - Good overview, verify details |
| Forum/Social | Low - Anecdotal, cross-reference required |
