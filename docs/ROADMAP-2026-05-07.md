### Sprint D — Script Format & Sharing (~13 SP, ~2 sessions)

**Session D1 (~8 SP, 2 PRs):**

#### feat: Fountain/FDX Native Import — Issue #33 (5 SP)

**Why:** No competitor (including Screenplayer.ai) supports `.fdx` natively. PDF conversion degrades character CUE detection. This is a landing-page differentiator.

**Architecture:**
- `packages/orchestrator/src/director/parsers/fountain.ts` — Fountain plain-text parser
- `packages/orchestrator/src/director/parsers/fdx.ts` — Final Draft XML parser; FD10/FD12 variant handling
- `packages/web/app/api/projects/upload/route.ts` — extend accepted MIME/extension list; route to correct parser
- `packages/web/components/` — file input `accept` extended; project header shows file type badge

**Tests:** `parseFountain.test.ts` (5 cases), `parseFDX.test.ts` (3 cases), upload route tests for `.fountain` and `.fdx`

**Branch:** `feat/fountain-fdx-import`

| Layer | SP |
|-------|----|
| Fountain parser | 1 |
| FDX parser | 1 |
| Upload route extension | 1 |
| Frontend changes | 1 |
| Tests | 1 |
| **Total** | **5** |

#### feat: Scene-Level Audio Sharing — Issue #35 (3 SP)

**Why:** No competitor offers per-scene share URLs. A writer pitching to an agent can send "listen to Act 2 Scene 3." Technically minimal; strategically differentiating.

**Architecture:**
- `ScriptShare` model: add `sceneIndex Int?` + `sceneStartMs Int?` fields; migration
- `POST /api/shares` — accept optional `{ sceneIndex, sceneStartMs }` in body
- `GET /api/shares/access/[code]` — include `sceneIndex` and `sceneStartMs` in response
- `packages/web/app/projects/[id]/listen/page.tsx` — on mount, read `?scene=N`, seek to `sceneStartMs`
- Project detail scene cards — "Share scene" icon button per scene; passes to `ShareModal`

**Dependency check:** Verify `director_json` has scene start timestamps before implementing. If not, compute from mixer timeline output.

**Branch:** `feat/scene-level-sharing`

| Layer | SP |
|-------|----|
| Schema + migration | 1 |
| API changes | 1 |
| Frontend seek + scene button | 1 |
| **Total** | **3** |

### Sprint E — Monetisation & Distribution (~13 SP, ~2 sessions)

**Session E1 (~8 SP, 1 PR):**

#### feat: Per-Scene Credit-Based Pricing — Issue #34 (8 SP)

**Why:** 28% of AI audio users cite "unexpected subscription costs" as their #1 frustration. All major competitors offer usage-based pricing. Credits solve the "one scene" trial problem without killing subscription ARR.

**Architecture:**
- `Profile.credits Int @default(0)` + `CreditTransaction` model; migration
- Stripe product: "20 Scene Credits" at $9.99 one-time (mode: `payment`)
- `POST /api/credits/purchase` → Stripe Checkout
- `POST /api/stripe/webhook` — new `payment_intent.succeeded` case → credit `+20`
- `GET /api/credits/balance`
- `POST /api/generate` — pre-generation credit check; atomic deduction; Pro/Enterprise bypass
- Frontend: credits balance badge; "Buy credits" CTA in generation modal; Account Settings credit tab

**Dependency:** Requires Stripe production keys (Ryan DEPLOY-02/03) before live testing. Can develop and test with Stripe test mode.

**Branch:** `feat/credit-pricing`

| Layer | SP |
|-------|----|
| Schema + migration | 1 |
| Stripe product + purchase route | 2 |
| Webhook handler + credit logic | 2 |
| Frontend balance + purchase flow | 2 |
| Tests | 1 |
| **Total** | **8** |

**Session E2 (~5 SP, 1 PR):**

#### feat: Audio-to-Podcast RSS Distribution — Issue #38 (5 SP)

**Why:** Once a screenwriter has finished audio, the natural next action is sharing with an audience. Story Magic becomes the only platform where a screenplay becomes a podcast in one workflow.

**Architecture:**
- `PodcastFeed` model: `projectId` (unique), `episodeTitle`, `description`, `coverArtUrl?`, `rssFeedSlug` (unique), `published`, `publishedAt?`; migration
- `POST /api/projects/[id]/podcast/publish` — validates completed audio; sets R2 object to public-read; creates feed
- `GET /listen/[code]/podcast.rss` — serves RSS 2.0 XML with `<enclosure>` M4A URL + iTunes tags
- `packages/web/app/listen/[code]/podcast/page.tsx` — cover art, inline player, RSS subscribe CTA, Apple Podcasts deep link
- Frontend: "Publish as Podcast" button on completed project; publish modal

**Security:** Podcast RSS contains public M4A URL. Ensure R2 object ACL is explicitly set to public-read on publish. Podcast URLs are permanent — no signed URL expiry.

**Branch:** `feat/podcast-rss`

|-------|----|

| Publish API | 1 |
| RSS generation | 1 |
