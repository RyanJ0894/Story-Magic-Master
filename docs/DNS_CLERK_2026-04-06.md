# DNS: Clerk Production Setup
**Action required by:** Ryan
**Where:** GoDaddy → DNS → storymagicapp.net
**Time:** ~5 minutes

---

Add these 5 CNAME records in GoDaddy. All are under `storymagicapp.net`.

| Type | Host | Value |
|------|------|-------|
| `CNAME` | `clerk` | `frontend-api.clerk.services` |
| `CNAME` | `accounts` | `accounts.clerk.services` |
| `CNAME` | `clkmail` | `mail.54ibwkghrsye.clerk.services` |
| `CNAME` | `clk._domainkey` | `dkim1.54ibwkghrsye.clerk.services` |
| `CNAME` | `clk2._domainkey` | `dkim2.54ibwkghrsye.clerk.services` |

---

## What each one does

- **`clerk`** — Routes sign-in/sign-up API calls through your domain (required)
- **`accounts`** — Account portal at `accounts.storymagicapp.net` (required)
- **`clkmail`** — Allows Clerk to send verification emails from `@storymagicapp.net`
- **`clk._domainkey`** / **`clk2._domainkey`** — DKIM email authentication so verification emails don't land in spam

---

## Steps in GoDaddy

1. Go to **GoDaddy → My Products → storymagicapp.net → DNS**
2. Click **Add New Record** for each row in the table above
3. Set Type = `CNAME`, enter the Host and Value exactly as shown
4. Save each record

Once added, go back to the **Clerk dashboard → Configure → Domains** and click **Verify** — the records usually propagate within a few minutes. All 5 should turn green.

---

*After these are verified, sign-in at https://app.storymagicapp.net will be fully production-ready.*
