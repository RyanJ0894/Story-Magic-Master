## Key Notes

> **Story Explorer** — Works only after a project completes audio generation (requires `director_json` populated by the orchestrator pipeline). This is expected behavior, not a bug.

> **Comparable Scripts** — 41 screenplays with OpenAI embeddings now in production `script_corpus`. Feature is live and searchable.

> **Corpus Seed** — Run `npx tsx packages/web/scripts/seed-corpus.ts` to add more entries. Uses `addToCorpus()` to auto-generate embeddings. Pass `--no-embed` for fast insert without API calls.
