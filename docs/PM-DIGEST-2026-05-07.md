## Market Position: Where We Stand

### The Category

The AI screenplay-to-audio category is **pre-consolidation** with no dominant player. The closest segment — AI TTS platforms — is consolidating fast (ElevenLabs at $11B valuation, $500M ARR). No TTS incumbent has built a screenplay-native automated pipeline. Story Magic is the only product that:

1. Parses Fountain/FDX natively (vs. PDF-only competitors)
2. Automates music + ambience + SFX selection per scene
3. Produces broadcast-standard -16 LUFS M4A output
4. Scores script quality (StoryScore) in the same workflow
5. Has an enterprise SOC 2 posture while the category is still indie-focused

## Overnight Sprint: What We Built (May 6–7, 2026)

### Sprint D: Competitive Parity — Script Format + Creative Control

**Fountain/FDX Native Import** *(PR #39 — 8 SP)*
- Built a spec-compliant Fountain parser (`orchestrator/src/director/parsers/fountain.ts`)
- Built a Final Draft XML parser supporting FD10 and FD12 variants (`parsers/fdx.ts`)
- Extended the upload UI to accept `.fountain` and `.fdx` files with format badges
- **Why it matters:** 100% of professional screenwriters write in Fountain or Final Draft. PDF export loses metadata, degrades character detection, and breaks formatting. This is a hard prerequisite for any studio client.

**Scene-Level Sharing** *(PR #39 — included)*
- Added `ScriptShare.sceneIndex` and `sceneStartMs` fields to the database
- Share modal now shows a "Share this scene" button per scene card
- Listen page reads `?scene=N` URL param and seeks the audio player to the correct timestamp on mount
- Shows "Sharing: Scene N of M" banner so the recipient knows they're entering mid-script
- **Why it matters:** Industry-specific use case — writers pitching to agents share the critical 10 minutes, not the full 90-page audio. No competitor offers this.

**Script Director Notes UI** *(PR #58 — 5 SP)*
- Added `Project.directorNotes` as a structured JSON field (`{ global: string, characters: { [name]: string } }`)
- Built `GET/PUT /api/projects/[id]/director-notes` with Zod validation (global: 500 chars, per-character: 2,000 chars)
- Added collapsible "Director's Notes" panel to the project page — auto-saves on blur
- Pipeline reads and injects these notes into Director Pass 1 as structured prompt context (sanitized, read-only)
- **Why it matters:** Zero competitors let users inject creative intent before generation. This deepens the pipeline moat precisely where ElevenLabs v3 Dialogue Mode is narrowing it.

### Sprint D (cont.): Business Model Expansion

**Per-Scene Credit System** *(PR #41 — 8 SP)*
- Added `Profile.credits` counter + `CreditTransaction` ledger with full audit trail
- New pricing tier: `POST /api/credits/purchase` → Stripe one-time payment at $9.99/20 credits
- Generation deducts credits atomically (no double-spend); Free tier gated; Pro/Enterprise bypass
- 3 signup bonus credits on new account creation
- Admin credit management for support team
- **Why it matters:** 28% of AI audio users cite forced subscription as their #1 frustration. Credits unlock the funnel for one-scene evaluation without subscription commitment.

### Sprint E: Distribution + Enterprise

**Audio-to-Podcast RSS Distribution** *(PR #42 — 5 SP)*
- `PodcastFeed` model with slug, cover art URL, episode metadata
- `POST /api/projects/[id]/podcast/publish` sets R2 object to public-read and creates feed
- `GET /listen/[code]/podcast.rss` — valid RSS 2.0 XML with `<enclosure>` M4A URL + `<itunes:duration>`
- Public podcast landing page at `/listen/[code]/podcast` with inline player and "Add to Apple Podcasts" deep link
- **Why it matters:** Screenwriters producing audio dramas now have a one-click distribution path to Apple Podcasts, Spotify, and any RSS-compatible platform.

**Emotion Cue Overrides Per Dialogue Line** *(PR #43 — 6 SP)*
- Added `Project.emotionOverrides` JSON field mapping dialogue IDs to emotion values
- `GET/PUT /api/projects/[id]/emotion-overrides` API
- "Performance" tab in project detail — emotion Select (neutral/happy/sad/angry/fearful/surprised/disgusted) per dialogue line
- "Re-render scene" button triggers targeted regeneration with new emotion tags
- ElevenLabs v3 audio tags injected where supported
- **Why it matters:** Direct response to WellSaid's AI Director feature (granular emotional control without full re-render). Now Story Magic matches this capability.

**Enterprise Direct Access** *(PR #44 — 2 SP)*
- Removed password gate for enterprise plan; existing enterprise accounts get direct access
- **Why it matters:** Removes friction from the enterprise trial flow identified in Ryan's April feedback.

### Sprint F: Platform & Developer Ecosystem

**Mobile PWA** *(PR #52 — included in 13 SP)*
- `manifest.webmanifest` with app icons, `standalone` display mode
- Service worker (`sw.js`) for offline asset caching
- `ServiceWorkerRegistration.tsx` component handles registration lifecycle
- Install prompt for iOS (Add to Home Screen hint in audio preview header)
- **Why it matters:** Writers review on their phones. Mobile access removes a platform barrier for evaluation and sharing.

**Voice Cloning** *(PR #52 — included)*
- `VoiceClone` model: name, label, ElevenLabs voice ID, status, preview URL
- Upload API: `POST /api/voice-clones` accepts audio sample
- `VoiceCloneUploader` component in Voice Marketplace
- Cloned voices appear in character voice assignment dropdown
- **Why it matters:** Production companies have SAG actors they want to use. Custom voice is the premium upsell that moves deals from "evaluation" to "contract."

**Audio Preview Hint** *(PR #52 — included)*
- 15-second contextual preview auto-plays on project completion
- Subtle notification with "Listen now →" CTA
- **Why it matters:** Reduces time-to-value; users who hear their script immediately have higher conversion to purchase.

**Public REST API + Webhooks** *(PR #53 — 8 SP)*
- `ApiKey` model with HMAC SHA-256 key display (shown once on creation)
- `WebhookEndpoint` model with HMAC SHA-256 signed payloads and retry queue
- `/api/api-keys` management endpoints (create, list, revoke)
- `/api/v1/generate` — queues audio generation jobs via API key
- `/api/v1/jobs/[id]` — polls job status
- Webhook events: `job.completed`, `job.failed`
- `/api/webhooks` endpoint management
- **Why it matters:** Production companies need to integrate Story Magic into their existing workflows (script management systems, production scheduling). API-first is the enterprise sales requirement.

### Sprint G: Enterprise Quality & Collaboration

**Human-in-Loop White-Glove Review** *(PR #54 — 13 SP)*
- `HumanReview` model: status (requested/in_review/delivered), reviewer notes, delivery URL
- `POST /api/projects/[id]/request-review` — creates review request
- Admin review queue at `/admin/human-review` with assign/deliver workflow
- Transactional emails: review requested (to admin), review delivered (to client)
- **Why it matters:** Direct competitive response to ElevenLabs Productions ($2/min managed service). Our positioning: professional audio producers review and polish every scene before delivery. This justifies premium pricing for studio clients.

**Team Comments & Collaboration** *(PR #55 — 8 SP)*
- `ProjectComment` model with scene index and audio timestamp anchoring
- `GET/POST /api/projects/[id]/comments` — accessible to project owner + TeamShare members + ScriptShare recipients
- `CommentsSidebar.tsx` component — threaded comments with scene/timestamp display
- Email notification to project owner when a collaborator posts
- **Why it matters:** Production companies have directors, producers, and writers who all need to react to the same audio pass. Without comments, Story Magic cannot become the team workflow standard.

## Competitive Strategy Notes for PM

**Where to focus the story:**
- Story Magic is the **only** audio production tool with a native Fountain/FDX parser + automatic scene-by-scene direction. This is the opening line of every pitch deck slide.
- The director notes feature is a **category-creating** capability — it does not exist anywhere else. Name it: "Story Magic Director Mode."
- Scene-level sharing is the **agency and pitch cycle** feature. Lead with this in writer/agent demos.
- Human-in-loop review is the **enterprise conversion** mechanism. Position it as "Story Magic White Glove Production."

**Competitive watch:**
- **Scriptmatix Studio Composer** (pre-launch): Video-first, but announced music + SFX + screenplay support. Establish brand/reviews before they launch.
- **ElevenLabs v3 Dialogue Mode**: Narrowing the voice-direction gap for DIY users. Story Magic's moat is the automated end-to-end pipeline, not individual voice quality.
- **Suno + AI music generation**: The pre-licensed music layer could be replaced with AI-generated per-scene music. This is a 6-month horizon item.
