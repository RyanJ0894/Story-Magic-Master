## Key Notes

> **#422 is the OOM lesson.** Six PRs of config knobs (#418–#421) couldn't fix what was fundamentally a 1-line `package.json` change. The env-var form of `NODE_OPTIONS` was being stripped before reaching `next build`; inlining the flag in the build script bypasses every layer of doppler/pnpm/worker stripping. Pinned to `feedback_next_build_oom_inline_node_options.md` so the next OOM saga starts with this lever pulled first.

> **#423 self-review caught a real BLOCKER.** Cleanup was stashed on `controller._sseCleanup` (the ReadableStreamDefaultController) but read via `this._sseCleanup` (the init object) — different references, the read returned `undefined`, every browser disconnect silently leaked a pg connection. Flag-OFF by default so dormant on dev, but would have drained the pool within hours of flipping on prod. Lesson: when adding ReadableStream cancel/cleanup wiring, hoist the cleanup closure to outer scope — don't lean on object-property roundtrips.

> **Sampling architecture A→E is in the codebase but unverified.** Flag-gated, defaults OFF, telemetry summarizer ready. Ryan owes sign-off on Phases A, C, D, E with two test scripts. Until that lands, the new agents stay in shadow/opt-in mode.

> **Stripe is still unverified end-to-end against live mode.** Runbook ready since 2026-06-13. ~45 min Chris time; net $0 cost. Launch gate.

> **Code Quality dropped a half-point** because the #423 cleanup bug shipped past the original PR's own unit-test suite. The TOCTOU regression test (in `job-listen-pool.test.ts`) pins the synchronous-reservation contract going forward. Worth a sweep across other recent SSE routes for the same controller-vs-this confusion pattern.
