## Key Notes

> **Branch protection in effect.** `main` requires 1 codeowner approval (Peter @octavianorg) + 3 CI checks. Never push directly or use `/cap` to main. All work via PR.

> **Doppler is env source of truth.** 76 secrets in `story-magic/prd`. Edit in Doppler, not Render. Native Doppler→Render sync requires manual dashboard activation per service (still pending).

> **Render PUT destructive.** `PUT /v1/services/{id}/env-vars` replaces the ENTIRE env var set. Always use `/render-env` skill or GET→splice→PUT pattern. Never PUT a partial list.

> **Migration renumbering.** PR #170 uses migration `0034_voice_catalog`. If it merges before PR #172 (`0035_timestamps_to_timestamptz`), the Sprint G migration number holds. If a branch already on `0034` merges first, `0035` may need to become `0036`. Check current highest migration at merge time.
